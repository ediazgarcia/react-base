# React + TypeScript + Tailwind CSS + Bun

Este proyecto base utiliza **React** con **TypeScript**, **Tailwind CSS** para los estilos, **Lucide React** para íconos, **Zustand** como gestor de estado, y **Bun** como gestor de paquetes ultrarrápido.

---

## Características principales

- **Rendimiento optimizado** gracias a Bun como gestor de paquetes.
- **Configuración inicial** con React y TypeScript.
- **Tailwind CSS** para estilos modernos y rápidos.
- **Lucide React** para íconos versátiles y personalizables.
- **Zustand** para una gestión de estado sencilla y escalable.

---

## Requisitos previos

- [Bun](https://bun.sh/) instalado en tu sistema.
- Node.js 16 o superior (para compatibilidad con algunas herramientas).

---

## Cómo iniciar el proyecto

### 1. Clona este repositorio e instala las dependencias

Clona este repositorio en tu máquina local y usa Bun para instalar las dependencias del proyecto:

```bash
git clone https://github.com/ediazgarcia/react-base.git

```

Luego ejecuta los comandos siguientes:

```bash
cd react-base
bun install
bun dev
```

## Scripts disponibles

```bash
bun dev :  Inicia el servidor de desarrollo.

bun build :  Genera la versión optimizada del proyecto para producción.
